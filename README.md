### Projects worth a look

**[java-algorithms](https://github.com/matgmarcelino/java-algorithms)**
Four projects in algorithm design and empirical analysis. Sorting algorithms with exact comparison counters verified across every permutation, the 0/1 knapsack problem solved greedily, exhaustively, and with dynamic programming, and a Monte Carlo simulation running over a million turns.

**[knights-travails](https://github.com/matgmarcelino/knights-travails)**
Breadth-first search finding the shortest sequence of knight moves between any two squares on a chessboard, with an interactive board that renders the path it found. Graph traversal with a visual answer to why BFS guarantees the shortest route.

**[maze-solver-dijkstra](https://github.com/matgmarcelino/maze-solver-dijkstra)**
Dijkstra's algorithm applied to grid-based pathfinding, with a graph representation built from maze input.

**[WeatherApp](https://github.com/matgmarcelino/WeatherApp)**
Vanilla JavaScript weather client with no frameworks or icon packs. REST API consumption, hand-drawn inline SVG icons with tone-based coloring, and automatic light/dark theming.
