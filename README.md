### 🧠 Algorithms and data structures

**[java-algorithms](https://github.com/matgmarcelino/java-algorithms)**: Four projects focused on measuring algorithms, not just writing them. Sorting algorithms with exact comparison counts verified across every permutation, the 0/1 knapsack solved greedily, by brute force, and with dynamic programming, set and multiset implementations, and a Monte Carlo board game simulation running over a million turns.

**[maze-solver-dijkstra](https://github.com/matgmarcelino/maze-solver-dijkstra)**: Models a maze as a weighted graph and finds the shortest walkable route with Dijkstra's algorithm, animating the search on screen. Tested with JUnit 5.

**[data-structures-js](https://github.com/matgmarcelino/data-structures-js)**: Linked list, hash map with load-factor resizing, balanced BST, and merge sort, built from scratch with private class fields and tested with Jest.
